




# Vulnerabilities in password-based login

## Username enumeration

User enumeration is a common vulnerability that can `expose valid usernames` through `subtle differences` in application behavior—such as `error messages` or `response timing`.

When brute-forcing a login page, watch for differences in:

- **Status codes:** A different HTTP status code from the norm likely indicates a valid username.
- **Error messages:** Distinct messages for "wrong username + password" vs. "wrong password only" can reveal valid usernames — even a single hidden character difference matters.
- **Response times:** Deviations from typical response times may signal a valid username (e.g., password validation only triggers after a valid username is found). Using an excessively long password can amplify this delay.
